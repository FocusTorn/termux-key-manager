# TKM Shell Commands

TKM generates shell functions into:

    ~/.termux/helpers.sh

The current helper set is:

| Command | Purpose |
|---|---|
| `cpy` | Copy the current tmux pane |
| `cpy_all` | Copy the current tmux pane including scrollback |
| `cpy_pytest` | Reduce clipboard content to the latest pytest result |
| `clr` | Clear terminal state |
| `refresh` | Regenerate TKM configuration and reload the helper environment |

## cpy

Captures the current tmux pane, removes the triggering `cpy` command, removes trailing blank lines, and sends the result to `termux-clipboard-set`.

## cpy_all

Captures the current tmux pane including scrollback, removes the triggering `cpy_all` command, removes trailing blank lines, and sends the result to `termux-clipboard-set`.

## cpy_pytest

Reads the clipboard with `termux-clipboard-get`.

It searches for lines that look like pytest progress and end in `[100%]`. The latest matching run is selected. The clipboard is replaced with the text beginning at that result section.

If no recognized pytest progress line exists, the clipboard remains unchanged.

## clr

When running under tmux, TKM sends Ctrl-C, sends the tmux cursor/line reset sequence, and clears tmux history.

Outside tmux it emits Ctrl-C, emits the terminal reset sequence, and runs `clear`.

## refresh

Runs:

    python "$HOME/projects/termux-key-manager/update.py"

After a successful update it sources the generated helper file, updates tmux's global `HISTIGNORE` when running under tmux, and sources `~/.bashrc`.

## Important boundary

These are shell functions generated by TKM. They are not standalone TKM executables.

Bash history records commands, not terminal output. Output-copy helpers obtain terminal content through tmux capture.
